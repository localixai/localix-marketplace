# Starter

The mini app `mini-app create` copies: one collection of items the agent and the screen share, agent
tools to add, list, change, remove and find them, a list screen with its loading, empty and error
states, and tests for both sides. A copy gets its own README and AGENTS.md; this folder's are not
copied.

`mini-app check template --template` checks it as a starter: it passes every gate and reports only
what a copy must replace.
